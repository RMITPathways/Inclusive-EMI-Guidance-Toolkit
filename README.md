# Inclusive EMI Guidance Toolkit

An interactive toolkit for Vietnamese higher-education educators teaching through English-medium instruction (EMI).

## About the project

This toolkit helps educators explore common student difficulties and identify practical teaching strategies. Users can select a difficulty area, explore associated strategies, view subject-specific examples and access supporting guidance and sources.

## Intended users

The primary users are Vietnamese educators who teach, or are preparing to teach, through English-medium instruction.

## Current structure

The toolkit includes:

- student difficulty areas;
- associated teaching strategies;
- practical classroom guidance;
- subject-specific examples;
- supporting sources;
- planning checklists and downloadable resources.

## Project status

This is a developing prototype. Content and examples require review and local validation before formal publication or institutional use.
